# Исходники

Приложение — `index.html` в корне плюс этот каталог. `index.html` хранит `<head>`
(meta, OG-карточки, иконка), разметку `<body>`, importmap three.js и загрузчик;
стили подключены ссылками `<link href="src/css/…">`, код — списком `SRC` в
загрузчике. Сборки нет: страница открывается с `file://` двойным кликом как есть.
Один файл для деплоя или пересылки склеивает `node tools/bundle.mjs` → `dist/index.html`
(каталог в `.gitignore`).

```
index.html       шапка, разметка, importmap, загрузчик со списком src/js/*.js
src/css/*.css    стили, порядок = каскад (подключены <link> по одному)
src/js/*.js      фрагменты ОДНОГО скрипта — общая область видимости, см. ниже
```

## JS: один скрипт, много файлов

three.js на CDN — ES-модуль, а ES-модули с диска Chrome не грузит. Поэтому
загрузчик (inline `<script type="module">` в `index.html`) импортирует three.js и
`OrbitControls`, кладёт их в `window` и подключает `src/js/*.js` обычными
`<script src>` в порядке списка. Обычные скрипты делят одну глобальную область:
`const`/`let`/`function` верхнего уровня видны из любого файла, присваивание
общим `let` (`components`, `chal`, `lang`, `theme`…) работает как в одном файле.
Правила:

- **Первая строка каждого файла — `'use strict';`** (обычный скрипт без неё
  нестрогий; `tests/check.mjs` это проверяет).
- Код верхнего уровня, выполняемый при загрузке, может ссылаться только на файлы
  **выше** по списку (функции из файлов ниже ещё не объявлены). Функции и
  обработчики, вызываемые после старта, видят всё.
- Новый файл: имя `NNN-тема.js` с номером в свободном промежутке своего блока
  (шаг 10 под вставки) **и строка в списке `SRC` в `index.html`** — `check.mjs`
  сверяет список с каталогом.
- Блоки `/* @pure имя */ … /* @pure end */` — код без DOM (реестры, кодек,
  валидатор); `tools/pure.mjs` вырезает их для `tests/codec.test.mjs` и
  `tools/schema.mjs`. Маркеры — внутри одного файла.
- Ошибка в `node tests/check.mjs` указывает на `src/js/файл:строка`.

## Тесты и сборка

`tests/run.mjs` кладёт в `tests/out/` копию `index.html` с путями на `../../src/`
и подменённым `900-main.js`, в который после `renderPanel();` вставлен сценарий;
`--bundle` гоняет тот же сценарий на склейке `tools/bundle.mjs`. Ошибки в
скриптах с `file://` браузер маскирует как «Script error.» — за настоящим текстом
запускайте `node tests/run.mjs имя --http`.

`tools/bundle.mjs` читает `index.html`: `<link>` стилей → один `<style>`, список
`SRC` → один `<script type="module">` с `import` three.js (директивы
`'use strict'` снимаются — модуль строгий сам). `buildModule()` оттуда же отдаёт
склеенный модуль тестам и `pure.mjs`.
