Новые фичи
- 🟡 Программа движений: журнал действий, плавный повтор, остановка, откат и цикл реализованы внутри режима заданий. Именованных шагов с пользовательской длительностью, отдельной общей вкладки и `?m=` пока нет; команды на ESP32 передаются через двойник вместо отдельного G-code.
- ✅ Обратная кинематика: цель перетаскивается мышью/касанием, солвер подбирает углы, показывает недостижимую цель и повторяет попытку после перестройки руки.

- Область достижимости: облако точек по выборке суставного пространства, наглядно показывает, что даёт рельс или лишнее звено.

- Экспорт STL/GLTF через встроенный экспортер three.js для печати и превью; PWA для офлайна.
- ✅ Цифровой двойник: вкладка с Web Serial и WebSocket, двусторонняя синхронизация поз, JSON-протокол, хаб и MCP-сервер. Для живого ESP32 всё ещё нужна совместимая прошивка.
