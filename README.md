# 🦾 Robo-Arm Builder (Конструктор робо-руки)

Интерактивный 3D-конструктор роботизированных манипуляторов на [three.js](https://threejs.org/).
Весь проект — **один файл `index.html`**: без сервера, без сборки, открывается двойным кликом в браузере.

![Robo-Arm Builder](scr/screenshot.png)

## Возможности

- **Последовательная сборка руки от основания**: yaw (турель), pitch (наклон), roll (вращение),
  link (звено), prismatic (телескоп), ball joint (шаровой), offset (кронштейн),
  rail (линейный рельс), gripper (схват), suction cup (вакуумная присоска).
- **Живое управление** — слайдеры каждого сустава двигают руку в реальном времени.
- **Зоны движения** — полупрозрачные пунктирные плоскости/сектора показывают диапазон каждого
  сустава (отключаются галочкой «zone (зона)» на компоненте).
- **JSON-конфигурация** — структура руки сериализуется в редактируемый JSON: копируйте удачные
  конфигурации и возвращайте их кнопкой Apply.
- **🎲 Generate Arm** — генератор случайных рук по логике реальных манипуляторов.
- **Auto Animate** — плавная синусоидальная анимация всех суставов.
- **Авто-камера** — камера сама отъезжает, если рука выходит за кадр; ре-фрейм при генерации.
- **🛒 BOM (список закупки)** — по текущей руке считается спецификация: моторы NEMA 17/14,
  драйверы TMC2209, редукторы, концевики, питание — с количеством, ориентировочными ценами
  и итоговой суммой. Вверху — название руки в принятой номенклатуре
  («4-осевой манипулятор с захватом»).

## Запуск

Откройте `index.html` в браузере. Нужен только интернет для CDN three.js (jsdelivr).

## Формат JSON

```json
[
  { "type": "yaw",     "angle": 0 },
  { "type": "pitch",   "angle": 40 },
  { "type": "link",    "length": 1.2 },
  { "type": "roll",    "angle": 0 },
  { "type": "gripper", "open": 60 }
]
```

Типы: `yaw` · `pitch` · `roll` · `link` · `prismatic` · `spherical` · `offset` · `rail` · `gripper` · `suction`.
